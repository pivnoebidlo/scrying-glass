# Scrying Glass

[English](README.md) · **Русский**

Экран мастера для настольных сессий (D&D 5e, Fate Core, Mausritter и Forged in the Dark): у мастера окно управления, у игроков на втором мониторе — портреты, фон, карты
с туманом войны, раздатка, трекер инициативы; плюс музыка и атмосфера, сцены и бестиарий с листами персонажей.

При запуске приложение проверяет, не вышла ли новая версия (спрашивает у GitHub, больше ничего не передаёт): если
вышла — вверху окна плашка «Скачать» / «Пропустить эту версию». Отключается в ⌘, → «Общие» → «Обновления», там же
«Проверить сейчас».

Интерфейс — на английском и русском (⌘, → «Общие» → «Язык»; по умолчанию — язык системы, если он есть среди
переводов, иначе английский). Язык переключается сразу, без перезапуска. Там же тема окна
мастера — автоматически (как в системе), тёмная, светлая, «Пергамент» (фэнтези), «Космос» или «Неон» (научная фантастика, киберпанк) (⌘, → «Общие» → «Тема»); экран игроков
выглядит по-прежнему. Полоса вкладок — это заголовок окна, как в Obsidian (окно перетаскивается за пустое место):
в macOS включено, в Windows и Linux — бета, системные кнопки там в правом верхнем углу — ⌘, → «Общие» → «Вкладки в
заголовке окна» (сразу). Над боковой панелью — поиск (⌘K), журнал бросков, корзина (с числом удалённого) и «Скрыть»; когда панель скрыта, «Показать» — в начале полосы
вкладок. В конце полосы — список всех вкладок с полными названиями. В заголовке «Экран игроков» — его состояние
(точка: закрыт, открыт, затемнён), быстрые «Открыть / Закрыть» и «Затемнить», и «Скрыть»: скрытая панель оставляет
точку и «Показать» в конце полосы вкладок. Встроенный справочник
и справочник Fate тоже есть на обоих языках и показываются на языке интерфейса.

## Установка

Готовые сборки — на странице Releases репозитория (только 64-битные системы):

- macOS (Apple Silicon): `scrying-glass-<версия>-mac-arm64.dmg`, macOS (Intel): `…-mac-x64.dmg`
- Windows: `scrying-glass-<версия>-windows-setup.exe`
- Linux: `.deb` (Debian, Ubuntu), `.rpm` (Fedora, openSUSE) или `.AppImage` (любой дистрибутив)

Приложение не подписано сертификатами Apple и Microsoft, поэтому при первом запуске система предупредит:

- **macOS**: «Не удаётся проверить разработчика» или «Приложение повреждено». Перетащите приложение в «Программы»
  и выполните в Терминале `xattr -cr "/Applications/Scrying Glass.app"` — или откройте «Системные настройки →
  Конфиденциальность и безопасность» и нажмите «Всё равно открыть».
- **Windows**: SmartScreen — «Подробнее» → «Выполнить в любом случае».

## Разработка

    npm install
    npm run dev        # разработка: окна перезагружаются при сохранении
    npm run build      # сборка в out/
    npm start          # запуск собранной версии
    npm test           # тесты ядра
    npm run typecheck  # проверка типов
    npm run import-srd # пересобрать встроенный бестиарий из SRD (нужен интернет)
    npm run import-compendium # пересобрать встроенный справочник SRD (нужен интернет)
    npm run build-fate # собрать встроенный справочник Fate из scripts/fate-core.<язык>.md
    npm run build-fitd # собрать встроенный справочник Forged in the Dark из scripts/fitd.<язык>.md
    npm run build-mausritter # встроенные существа и справочник Mausritter из scripts/mausritter-srd.<язык>.md
    npm run dist       # установщик для своей системы в dist/ (electron-builder.yml)
    npm run icon       # иконка build/icon.png из build/icon.svg

Выпуск версии: поднять `version` в package.json, закоммитить, `git tag v<версия>` и `git push origin v<версия>`.
GitHub Actions (`.github/workflows/release.yml`) соберёт macOS arm64 и x64, Windows x64, Linux x64 (deb, rpm,
AppImage) и создаст черновик релиза — его остаётся проверить и опубликовать.

## Хранилище

При первом запуске приложение просит выбрать папку хранилища, как в Obsidian. Внутри может быть любое дерево:

    D&D/
    ├── Тыквенный фестиваль/
    │   ├── characters/
    │   ├── monsters/                ← карточки монстров и NPC этого приключения
    │   └── фоны/
    └── Проклятие Страда/
        ├── characters/              ← сквозные персонажи кампании
        ├── Глава 1. Деревня Баровия/
        │   ├── персонажи/
        │   ├── maps/
        │   └── music/
        └── Глава 2. Валлаки/

Вкладка **«Приключения»** — первая в полосе: каждое приключение плиткой с обложкой, системой, тем, что в нём есть
(сцены, бои, карточки, заметки), и его состоянием в «Сообществе». «Открыть» делает его текущим; «⋯» — название и
система, обложка, экспорт, публикация, удаление. Картинка, перетащенная на плитку, становится обложкой (`cover.jpg` в
папке приключения: она переезжает вместе с ним и служит обложкой в «Сообществе»). Переименование переносит всё, что
приложение знает о приключении; опубликованное остаётся той же записью в «Сообществе» — повторная публикация станет
его новой версией.

**Дополнения** — там же: содержимое для приключений — существа и записи справочника (заклинания, предметы, правила,
свои типы записей), в любом сочетании. «Создать дополнение…» спрашивает название, что это (бестиарий, заклинания,
предметы, правила, таблицы с броском, сборник) и систему. Щелчок по дополнению открывает его страницу: слева существа и записи (с «+» —
новое создаётся прямо в дополнении, вопроса «где хранить» нет), справа выбранное или его редактор, сверху «Подключено
к:» — галочки приключений, которые им пользуются (то же — в «Название и система…» приключения). Приключение видит
существ и записи подключённых дополнений как свои. «Опубликовать…» отправляет дополнение целиком (существа, записи,
картинки) в «Сообщество», в раздел «Дополнения», с подписью, о чём оно; скачанное ложится в хранилище дополнением —
его можно сразу подключать к приключениям, а новые версии приходят, как у приключений. «Экспорт…» сохраняет его в
файл (обратно — «Импорт приключения…», возвращается дополнением).

**Таблицы с броском** — записи справочника типа «Таблица с броском», делаются без всякой разметки: «+» у «Таблиц с
броском» на странице дополнения, «Новая таблица» в «Инструменты» → «Таблицы с броском» или «+» в «Справочнике».
Редактор: куб кнопками (к4…к100, 2к6 или любые кубы), строки — диапазоны и результаты (разделить, объединить,
добавить; предупреждение называет числа, для которых нет строки), «Сетка» — второй куб для столбцов (таблица критов:
строки к10 × столбцы к6). «Бросок в тексте» вставляет в результат `{1к6}` (кидается вместе с таблицей; результат может быть в несколько строк — Enter), «Ссылка на
таблицу» — ссылку на другую таблицу: она тоже бросается, так таблицы идут цепочкой (крит → часть тела →
последствие). «Вставить из текста…» делает таблицу из нумерованных строк или списка, скопированных из PDF или с
сайта. «Бросить» у записи (или кнопка с кубиком в «Инструменты» → «Таблицы с броском», где собраны все таблицы,
видные здесь) кладёт всю цепочку в журнал бросков; там — «Ещё раз», «Показать игрокам» и «В Telegram». Если игроки
бросают свои кубики, введите число в «Выпало» рядом с «Бросить» и нажмите Enter или просто щёлкните по результату в
таблице: он попадёт в журнал так же (таблицы по ссылкам приложение по-прежнему бросает само). В «Предлагать
в журнале бросков» таблицу отмечают на события: натуральная 20 или 1, начало боя, новый раунд, участник выбыл (хиты
кончились; в Mausritter — СИЛ 0), прошла стража (Mausritter). Когда это случается, в журнале появляется строка
(«Гоблин · выбыл(а)») с кнопкой каждой отмеченной таблицы — само приложение не бросает; нет таких таблиц — нет и строки.
Внутри таблица — обычный файл Markdown (таблица с диапазонами в первом столбце и поле `roll`), поэтому она
путешествует вместе с дополнением, и её можно править руками.

Приключения — папки первого уровня хранилища, отмеченные приключением: кнопкой «Создать приключение…»
в переключателе над боковой панелью или «Сделать приключением» во вкладке «Файлы» (при первом открытии
приключениями становятся папки, в которых уже есть characters, maps и т. п.). В приключении всегда есть папки
characters, monsters, backgrounds, maps, music — недостающие создаются при запуске. Все вкладки, кроме «Файлов»,
показывают текущее приключение и «общее» — то, что лежит вне приключений (например, music в корне хранилища).
Сцены принадлежат приключению; сцены из прошлых версий общие, приключение им можно назначить в редакторе сцены.
В переключателе — пять последних открытых приключений (дополнений там нет); остальные — в «Все приключения…»,
то есть во вкладке «Приключения».
«Файлы» показывают хранилище целиком, как файловый менеджер: ↑ ↓ — соседняя папка, → — раскрыть или войти,
← — свернуть или подняться (так же стрелки работают во всех списках слева: журнал, справочник, карточки,
инструменты, сцены, карты, музыка). Выбранная папка приключения (или любая папка внутри него) сразу открывает это
приключение; корень и общие папки текущее приключение не меняют.

Назначение папок угадывается по названию: characters / персонажи / npc — портреты, party / партия / игроки — персонажи игроков,
backgrounds / фоны / locations / локации — фоны, handouts / раздатка / улики / записки — раздаточные материалы,
maps / карты — карты, music / музыка — музыка,
monsters / монстры / bestiary / бестиарий / creatures / существа — карточки бестиария,
journal / журнал / заметки / notes — журнал мастера.
Названия можно поменять или дополнить своими в настройках (⌘, → «Файлы» → «Назначение папок»); первое
название роли — то, с которым приложение само создаёт папки.
Картинку из любой папки тоже можно показать игрокам через «Файлы».
Подпись под портретом у игроков можно оформить (⌘, → «Персонажи»): просто текст с тенью, лента, свиток или
табличка, свой цвет и любой из шрифтов записок; образец виден сразу. Подпись — название карточки, у которой эта картинка стоит портретом, иначе имя файла
(подчёркивания становятся пробелами). Если игроки ещё не знают имени персонажа, кнопка «?» у его строки в блоке
«Персонажи» правой панели показывает им «???» вместо подписи. Название под любой плиткой (портрет, фон, раздатка, существо, файл в «Файлах»)
и в списке карт (двойной щелчок) можно поправить прямо там: у портрета с карточкой и у существа переименуется
карточка, у остальных — сам файл. Сцены, подборки, разметка карты и портреты карточек при этом не теряются.

Плитки по щелчку игрокам ничего не показывают — только своими кнопками. Ничего не прячется до наведения: на каждой
плитке всегда видны главная кнопка вкладки (портретом, фоном, раздаткой, показать) и «⋯» со всем остальным (другой
способ показать, в бой, Telegram, рисовать поверх, рассмотреть крупно, в корзину); правый щелчок открывает то же меню.
Списки (карты, сцены, журнал) устроены так же: главная кнопка видна всегда, остальное — правый щелчок или «⋯» у
выбранного.
Двойной щелчок по картинке открывает её крупно: ← → — соседние, Esc — закрыть, внизу — те же кнопки.

Любую картинку можно показать игрокам портретом (с подписью, несколько сразу) или на весь экран как фон:
локацию, раздатку, иллюстрацию. Фон лежит под портретами и притеняется, когда они на экране.
Оба варианта есть на любой плитке картинки: свой для вкладки — кнопкой, другой — в «⋯».

Раздатка: записки, улики, письма, карты сокровищ — если не хочется печатать их на бумаге. Вкладка «Раздатка»
показывает картинки из папок handouts / раздатка / улики; кнопка на плитке показывает материал игрокам поверх
карты и портретов (сцена за ним затемняется), повторное нажатие убирает. Любую картинку можно показать раздаткой
из её меню «⋯».

Записки: письма, приказы, объявления, дневники можно сделать прямо в приложении — раздел «Инструменты» → «Записки»
или кнопка «Новая записка» в «Раздатке». Текст (заголовки, курсив, жирный, украшение «---») на пергаменте, старой
или светлой бумаге или тёмной коже; край ровный, рваный или обгоревший; форма — лист, записка или свиток; бумага
гладкая, сложенная, помятая или скомканная; подпись. Следы ставятся щелчком по листу и перетаскиваются: брызги и
капли крови, мазки, кляксы, отпечатки пальцев, след от кружки, разводы, капли воска, подпалины, прожжённые дыры,
следы когтей, сургучные печати (со знаком или буквой, целые или сломанные) и чернильные штампы с надписью по кругу.
Перо рисует прямо по листу — карту к кладу, набросок, стрелки: чернила записки, три толщины, ластик и отмена (⌘Z); игроки
видят рисунок вместе с текстом. Редактор записки разделён на три части: текст и лист, перо, следы. Девятнадцать шрифтов с кириллицей: от руки, каллиграфия, книжные, старорусский, летопись, древняя рукопись, жуткие
(потёки, истёртый, чудовищный); «неровность почерка» заставляет буквы плясать. Записка — файл «Название.note.json» в папке раздатки приключения: она стоит в «Раздатке» и «Файлах»
рядом с картинками и показывается игрокам так же. Сохраняется сама; если записка у игроков, правки видны сразу.

**Холсты** («Инструменты» → «Холсты», «Новый холст» в «Раздатке» или «Рисовать поверх» на любой картинке) — раздатка,
которую рисуют: на листе бумаги, как у записок, на ровном цвете или поверх картинки из хранилища (сама картинка не
меняется). Перо, полупрозрачный маркер, линия, стрелка, прямоугольник и эллипс (контур, полупрозрачная или сплошная
заливка; Shift — квадрат, круг, шаг 15°), заливка (щелчок заливает фигуру или часть, закрытую линиями, — под рисунком, комнаты внутри залитого фона
остаются как были; протяжка — область от руки), текст шрифтами записок, ластик и
отмена (⌘Z). Холст показывается игрокам как любая раздатка — и пока он на экране, игроки видят каждую линию, пока вы
рисуете.

**Часы прогресса** (как в Blades in the Dark) — блок в правой панели, в приключениях Forged in the Dark: круг из 4, 6, 8 или 12 делений
для угрозы, которая приближается («Стража поднимает тревогу»), или дела партии («Взлом хранилища»). Щелчок — деление
вперёд, правый щелчок — назад; глаз показывает часы игрокам — в выбранном углу и размере; полные часы светятся. У
каждого приключения свои; они переезжают с ним в .sgpack и уходят с ним в корзину.

Справочник (отдельный раздел в полосе слева): заклинания, предметы, черты, состояния, правила и заметки — то, что
ищут прямо на игре. Запись — Markdown-файл: в папке compendium / справочник приключения, в общей папке хранилища
или в библиотеке (для всех кампаний); её удобно править и в Obsidian. Поля — в «свойствах» в начале файла:

    ---
    type: spell
    level: 3
    school: Воплощение
    casting_time: 1 действие
    tags: [огонь, урон]
    ---
    Яркая вспышка… [[Ослеплённый]]

Встроены заклинания, магические предметы, черты, состояния и глоссарий правил из SRD 5.1 и SRD 5.2.1 — на
английском (оригинал) и в русском переводе OmnisGM, на языке интерфейса (над списком выбирается редакция, обе или
никакая). Их можно править: правка сохраняется в библиотеку
(для всех кампаний) и заменяет встроенную запись везде — в списке, поиске, ссылках; «Вернуть как в SRD» убирает
правку. «Копия в…» делает отдельную запись. Искать можно и по названию на другом языке (fireball — «Огненный
шар», и наоборот); ссылки на заклинания из карточек тоже находят запись на любом языке.
Заклинания можно отфильтровать, как на dnd.su: уровень, класс, школа, время накладывания, концентрация, ритуал
(фильтр появляется, когда выбран тип «Заклинания»); список — по уровням с заголовками или по алфавиту.

Справочник под рукой из любой вкладки:
- заклинания в статблоках (курсивом, как в SRD) и в списках заклинаний листа персонажа — ссылки: щелчок открывает
  запись в выдвижной панели, «назад» в ней возвращает к карточке;
- состояния в трекере инициативы: щелчок по названию — описание, крестик — снять;
- ⌘K (Ctrl+K) — общий поиск по записям, карточкам и заметкам журнала: Enter — открыть сбоку, ⌘Enter — во вкладке.

Переводы называют одно и то же по-разному («Чудотворство» и «Тауматургия»): в поле «Другие названия» (`aliases`,
как в Obsidian) можно перечислить свои — запись найдётся и по ним, в том числе в листе персонажа.

Свои типы записей — кнопка с фигурами рядом с «+» в списке: например, «Божество» с полями «Мировоззрение» (выбор из
списка), «Домены» (список), «Символ». Для поля задаются подпись, ключ в шапке файла, вид (текст, число, да/нет, выбор,
список), подсказка и нужно ли писать его в строке под названием («Божество, законно-доброе, Война, Знание»). Типы
общие для всех кампаний (лежат в библиотеке); записи своих типов создаются «+», правятся и показываются игрокам,
как остальные.

Типы: заклинание (`spell`), предмет (`item`), черта (`feat`), состояние (`condition`), правило (`rule`), заметка
(`note`); запись неизвестного типа показывается как «поле — значение». Слева — поиск (по названию, меткам и тексту)
и типы, «+» — новая запись (тип и место); в тексте — заголовки, списки, таблицы и [[ссылки]] на другие записи или
на карточки монстров, «Назад» — к прошлой записи. «Показать игрокам» выводит запись на экран игроков листом
бумаги (длинная уменьшается, чтобы поместиться); у записи может быть картинка (предмет, место) — игроки увидят её
вместе с текстом. Там же — правка с предпросмотром (Enter,
⌘B / ⌘I / ⌘⇧X и Tab — как в журнале), копия в другое место, открыть
файл в другой программе, удалить в корзину.

Журнал (отдельный раздел в полосе слева) — заметки мастера к приключению: план сессии, текст, который нужно
зачитать игрокам, итоги игры, идеи по сюжету. Заметка — обычный Markdown-файл в папке journal / журнал приключения
(или в общей папке хранилища), её удобно править и в Obsidian. Слева — дерево заметок: папки («Сессии», «Локации»,
«Идеи»). «Заметка» и «Папка» над деревом создают в выбранной папке (на которой щёлкнули или в папке открытой заметки).
Правый щелчок по заметке, PDF или папке — или «⋯» у выбранной — открывает её действия: новая заметка или папка здесь,
переименовать, перенести в…, закрепить, открыть в другой программе, в корзину. Порядок — перетаскиванием,
перетаскивание на папку переносит в неё заметку, PDF или папку; папку можно переименовать и двойным щелчком. Заметка открывается оформленной, «Править» (⌘E) — Markdown-текст, сохраняется сам. Как в Obsidian, Enter переносит
на новую строку цитату «>», список, задачу или номер (Enter на пустом пункте заканчивает список), ⌘B / ⌘I / ⌘⇧X
делают выделенное жирным, курсивом или ~~зачёркнутым~~ (повторно — снимают), ⌘⇧. — цитата, ⌘Z отменяет; то же и
ещё заголовок, список, задача, [[ссылка]], бросок {1d20} — кнопками над текстом (отключаются в «Настройки» →
«Журнал»; они есть и в редакторе справочника):

    ## Прибытие в деревню
    > Дорога выводит вас к частоколу. Над воротами висит
    > выцветший венок из колосьев.

    Стражник просыпается: Скрытность {1d20+2} против 12. Староста — [[Староста Гилберт]].
    - [x] Встреча у ворот
    - [ ] Таверна

Цитата «>» — текст для зачитывания (выделенная плашка), «- [ ]» — задача с флажком (щелчок отмечает её прямо в
файле), {1d20+2} — бросок по щелчку в журнал бросков, [[Название]] — карточка, другая заметка или запись справочника
(в выдвижной панели; карточка важнее одноимённой заметки или записи). Заметки и PDF можно закреплять — сколько угодно: в правой панели будут их названия, под рукой на игре; щелчок открывает
закреплённое в выдвижной панели поверх любой вкладки, повторный — закрывает, булавка открепляет. Закрепление уходит вместе с
приключением в файл (.sgpack) и возвращается с ним из корзины. Заметки
находятся поиском ⌘K.

**Книги и приключения в PDF** тоже живут в журнале: перетащите PDF на вкладку «Журнал» или её значок, а то и прямо на
папку в дереве (или положите в папку журнала) — он появится в дереве рядом с заметками. Открывается прямо в приложении: страницы одна под другой,
текст выделяется, поиск (⌘F; Enter — следующее совпадение), номер страницы, масштаб и «по ширине»; каждый файл
открывается там, где его оставили. Чтобы подсмотреть на игре, не уходя из боя или с карты, закрепите его: из правой
панели он открывается в выдвижной панели поверх любой вкладки. [[Книга#12]] в заметке открывает 12-ю страницу PDF
«Книга» в выдвижной панели. PDF переименовываются, переносятся по папкам и удаляются, как заметки, и уходят с
приключением в .sgpack.

В боковой панели «Инструментов» — записки и общие инструменты (расписание, сообщение игрокам, таймер), ниже — раздел
системы текущего приключения: в D&D — генераторы (имена, NPC, таверны, поселения, лавки, предметы, подземелья, погода,
события, сокровища), сложность боя, покупка характеристик, переделка статблока и путь; в Mausritter — генератор мыши, таблицы Mausritter,
фракции и постройки; в Forged in the Dark — банда; у Fate своих инструментов пока нет. Инструменты других систем скрыты; настройки → «Инструменты» включают
нужный и в другой системе (он появится в разделе «Другие системы»), запоминает окно.

Сложность боя: у текущего боя и у каждой заготовки — плашка «Умеренная · 1 100 / 1 500 ОО», по щелчку — шкала и
подробности. Считается по правилам 2024 года (SRD 5.2): у каждого героя бюджет опыта по уровню (низкая, умеренная,
высокая), опыт противников складывается. Герои — из боя, а если их там нет — персонажи игроков приключения (уровень
из листа; герой без карточки ищется по имени); если героев нигде нет — партия из настройки в той же плашке.
Опыт — из карточек противников; союзники и нейтральные не учитываются. Набросать бой и подобрать противников можно
в «Инструменты» → «Сложность боя», оттуда — сразу «В заготовку боя».

Генератор имён («Инструменты» → «Генератор имён»): раса (человек, эльф, дварф, гном, полурослик, драконорождённый,
тифлинг), у человека — происхождение: общие имена или один из народов Забытых Королевств (калишиты, чондатанцы,
дамарцы, иллусканцы, муланы, рашеми, шу — фамилия перед именем, тетирцы, тёрами), пол, форма — только имя или имя и фамилия, прозвище — без, простое («Хромой») или эпическое («Гроза
драконов»). Фильтры — длина, звучание (певучее, мягкое, резкое) и первые буквы; сразу 1, 5, 10 или 20 имён, пробел —
ещё. У имени — «Копировать» и звёздочка «В избранное»; избранное (общее для всех кампаний, в библиотеке) и история
выгружаются в TXT и CSV. Встроенные списки написаны для приложения, на русском и английском. Свои списки — текстовые
файлы, по имени в строке, имя файла говорит, что в нём: `раса_пол_вид.txt` (`human_man_names.txt`,
`elves_woman_nicknames.txt`, `dwarf_surnames.txt`; виды — names, surnames, nicknames, epithets; раса `any` — для всех,
можно и свою: `orc_man_names.txt`). «Загрузить списки…» кладёт их в библиотеку (`names/<язык>/`, язык — по буквам), и
они добавляются к встроенным; встроенные или свои можно выключить.

Сокровища («Инструменты» → «Сокровища»): где (карманы, тайник или сундук, логово) и уровень героев (1–4, 5–10, 11–16,
17–20) → монеты, самоцветы и украшения, ценные вещи, мелочи из карманов и безделушки; любую часть можно перебросить.
В приключениях D&D — магические предметы нужной редкости из справочника (показанной редакции, свои тоже; щелчок
открывает запись, в журнале — [[ссылки]]) и цены с итогом в золоте; в других системах — диковины и без цен.
Копировать, в журнал или в Telegram.

Случайные события («Инструменты» → «Случайные события»): местность (как у погоды, включая город и подземье), день или
ночь, опасность (спокойно, напряжённо, опасно) и 1, 3 или 6 событий → встречи, находки, препятствия, путники, знамения и
слухи (из генератора таверн); любое событие можно перебросить. Существа в тексте — ссылки: щелчок открывает карточку
SRD сбоку (в журнале они остаются [[ссылками]]). В приключениях D&D у препятствия — проверка (навык и СЛ); на опасной
дороге событие может прийти с осложнением. «В заготовку боя» у встречи создаёт заготовку боя с её существами
(слабые приходят группой) и открывает её в «Инициативе». Копировать или в журнал.

Путь («Инструменты» → «Путь», только в D&D): расстояние в милях, пешком / верхом / в повозке или на корабле
(воздушный корабль, галера, парусник…), темп, местность, дорога и часов в день → время в пути и скорость по правилам
перемещения SRD редакции приключения. По правилам 2024 местность ограничивает темп (хорошая дорога поднимает предел
на ступень) и даёт дистанцию встреч и СЛ добычи пищи, ориентирования и поиска; в 2014 — труднопроходимая местность
вдвое сокращает путь. Ещё: что даёт темп (Внимательность, Скрытность), галоп верхом и долгий марш после 8 часов —
СЛ спасброска Телосложения за каждый лишний час. Корабли идут со своей скоростью, до 24 часов в сутки.

Дикая магия («Инструменты» → «Дикая магия», только в D&D): к100 по таблице всплесков — нашей (50 эффектов, написаны
для приложения), Волшебной палочки чудес редакции приключения (берётся из справочника SRD, ваша правка записи
учитывается) или своей: вставьте строки вида «01–02 Эффект», таблицу Markdown или по эффекту на строку (тогда куб —
по числу строк); свои таблицы хранятся в библиотеке. «Проверить всплеск» бросает к20 по правилам редакции
приключения (всплеск на 1 в 2014, на 20 в 2024) и при всплеске сразу бросает таблицу. Пробел — бросок, − и + сдвигают результат на единицу, заклинания
в тексте открывают справочник; копирование, отправка в Telegram, вся таблица с выпавшей строкой и броски этого окна.
Таблицы из Книги игрока и других книг закрыты, поэтому не встроены — вставьте их как свои.

Генератор подземелий («Инструменты» → «Генератор подземелий»): вид (гробница, пещеры, рудник, храм, крепость, башня
мага, стоки, руины), уровень героев и 5 или 8 комнат → подземелье по схеме «пяти комнат»: вход со стражем, загадка,
ловушка, финальная схватка и награда (в восьми — ещё логова и тихая комната); кто построил и что с ним стало, вход,
атмосфера и зацепка. Существа — карточки SRD по уровню (щелчок открывает карточку); в приключениях D&D у ловушек —
спасбросок, СЛ и урон по SRD, а клад — из генератора сокровищ с магическими предметами из справочника. Любую часть
можно перебросить; копировать или в журнал (существа и предметы — [[ссылками]]). «В заготовку боя» у комнаты с
существами создаёт с ними заготовку боя текущего приключения и открывает её в «Инициативе».

Генератор магических предметов («Инструменты» → «Генератор предметов»): вид (оружие, доспех, украшение, палочка или
посох, одежда, чудесная вещь) и сила (диковинка, малый, сильный, легендарный) → название, вид, малое свойство, кто
создал и что с ним было, причуда, а иногда и проклятие. В приключениях D&D у малого, сильного и легендарного предмета
есть основа — предмет SRD этой редкости из справочника (по возможности того же вида; ссылка на запись). Любую часть
можно перебросить; копировать, в журнал или в Telegram (без проклятия).

Генератор лавок («Инструменты» → «Генератор лавок»): лавка всякой всячины, кузнец, алхимик, магическая лавка, книги
и карты или старьёвщик, бедная, средняя или богатая → название и хозяин (из генератора NPC), вид изнутри и
особенность, товары с ценами и количеством, зацепка. Цены обычных товаров — по таблицам снаряжения SRD; в
приключениях D&D магическая лавка продаёт предметы справочника по ценам SRD (расходуемые — вдвое дешевле), названия
открывают записи; в других системах — диковины и без цен. Копировать, в журнал или в Telegram (без зацепки).

Генератор поселений («Инструменты» → «Генератор поселений»): хутор, деревня, город или большой город (или случайно) →
название, население и народы, кто правит и как защищено, первое впечатление для зачитывания, чем известно, места (с
таверной, названной генератором таверн), известные жители (из генератора NPC) и беда — завязка приключения. Любую
часть можно перебросить или закрепить; в журнал или копировать.

Генератор погоды («Инструменты» → «Генератор погоды»): местность (лес, равнины, город, побережье, горы, болото,
джунгли, пустыня, арктика, подземье), сезон и 1, 3 или 7 дней → на каждый день небо, дождь или снег (мокрый снег,
песчаная буря, гроза), ветер и температура, строка для зачитывания и изредка что-то необычное (северное сияние,
водяной смерч, мираж…). Дни идут один за другим: дождь затягивается, температура меняется плавно. В приключениях D&D —
правила погоды SRD, которые действуют (сильный холод и жара, сильный ветер, сильные осадки, туман). Копировать, в
журнал или сразу игрокам в Telegram (без правил).

Генератор NPC («Инструменты» → «Генератор NPC»): раса или народ человека (или случайно; человек в половине случаев — из одного из народов), пол, важность (от обычного до уникального) →
имя, занятие, внешность, характер, манера речи, чего хочет, что скрывает и что при себе; у важных — прозвище или эпитет,
слава и иногда волшебная вещица. Любую часть можно перебросить или закрепить; недавние NPC — в истории. «Создать
карточку» открывает в редакторе новую карточку NPC с уже заполненными именем, описанием и заметками; «В журнал» и
«Копировать» — как у таверн. Имена — из списков генератора имён.

Генератор таверн («Инструменты» → «Генератор таверн»): тип (таверна, постоялый двор, придорожный трактир, портовый
кабак, подпольный притон, винный погребок), достаток (от нищенского до роскошного — цены по таблице SRD «Еда, напитки и
ночлег»), людность, ночлег и чудеса. Получается: название и вывеска, описание для зачитывания, хозяин (имя, черта,
любимая фраза, секрет), прислуга, посетители — чем заняты и что скрывают, меню с ценами (что подают — по достатку и виду
заведения: в роскошном нет сивухи, в порту — рыба, в погребке — вина; «Меню в раздатку» делает записку в папке
раздатки — мелом на доске в притоне, на веленевой бумаге у богачей), комнаты и услуги, событие
вечера с участием здешних людей, слухи, просьба и тайна заведения. Любую часть можно перебросить или закрепить
(«Перебросить незакреплённое» не тронет закреплённые); «В журнал» сохраняет таверну заметкой текущего приключения
(описание — цитатой для зачитывания, слухи — флажками), «Копировать» — тот же текст. Имена — из списков генератора
имён, в том числе своих.

Картинку, открытую крупно (двойной щелчок), можно скопировать в буфер обмена: кнопкой «Копировать» или ⌘C / Ctrl+C.

Telegram: картинки, записки, записи справочника и сообщения можно отправить игрокам через своего бота. Создайте бота
у @BotFather (/newbot) и вставьте токен в ⌘, → Telegram (токен хранится только на этом компьютере, зашифрованным;
приложение обращается к Telegram напрямую, без своего сервера). Игроки пишут боту /start, для общего чата бота
добавляют в группу — чаты появляются в настройках выключенными, включайте только своих и подпишите, кто чей игрок.
Отправить: кнопка «Telegram» на плитке картинки и записки (записка уходит картинкой, крупно, как её видят игроки),
самолётик в редакторе записки и у записи справочника (текстом), самолётик в блоке «Раздатка» правой панели — то, что
игроки видят сейчас, «Инструменты» → «Сообщение игрокам» — свой текст. В окне отправки — кому: общий чат
и/или игроки лично.

Ответы приходят обратно: что игроки пишут во включённый чат (текст, фото, стикеры; голосовые и файлы — с пометкой
открыть их в Telegram), появляется в «Инструменты» → «Сообщение игрокам» перепиской, рядом с тем, что отправило
приложение, вместе с картинками. О новом сообщении — уведомление в углу (щелчок открывает переписку) и счётчик у
инструмента. Выберите чат справа, чтобы писать в него сразу; ↩ у сообщения — ответ на него. Enter отправляет,
Shift+Enter — новая строка (или ⌘Enter отправляет — ⌘, → Telegram). Оформление — клавишами Telegram Desktop: **жирный** ⌘B,
*курсив* ⌘I, __подчёркнутый__ ⌘U, ~~зачёркнутый~~ ⌘⇧X, `моноширинный` ⌘⇧M, ||спойлер|| ⌘⇧P (скрыт, пока не коснутся);
списки «- », цитаты «> ».

О программе (⌘, → «О программе» или меню приложения): версия, ссылки проекта (GitHub, сообщить о проблеме, выпуски),
лицензия (GPL-3.0-or-later, без гарантий) и авторство материалов других авторов, которые входят в приложение. Меню
приложения — на языке интерфейса; «Справка» ведёт на страницы проекта.

Столы (⌘, → Telegram → «Столы»): стол — это люди, которые играют вместе, поэтому одно приключение можно водить для
нескольких столов. Укажите у каждого чата его стол; в переписке выберите, за каким столом играете сейчас (над
чатами), — чаты, окно отправки, счётчики и уведомления покажут только его чаты и чаты без стола. Приключение
запоминает стол, с которым в него играли последним, и выбирает его при переключении. Картинку можно вставить (⌘V), перетащить на
поле или прикрепить кнопкой — текст уйдёт подписью к ней. Свои сообщения можно удалить у всех (Telegram позволяет это
48 часов); любое сообщение можно скрыть в приложении. В группе бот видит только ответы на свои сообщения и
упоминания — чтобы видеть всё, выключите ему приватность: @BotFather → /setprivacy → Disable. Переписка хранится на
этом компьютере (`<данные приложения>/telegram`, последние 300 сообщений); корзина очищает её только в приложении.

Расписание («Инструменты» → «Расписание»): ваши игры — дата и время, длительность, повтор (каждую неделю или раз в две,
до какого дня, с пропусками), стол, приключение и его план (заметка журнала), место (адрес или ссылка на онлайн-комнату).
У анонса есть необязательные строки — каждая уходит, только если заполнена: картинка сверху, вид игры (ваншот, кампания,
сессия) с названием, количество участников, цена, мастер, система (из приключения), уровень персонажей и описание (с
оформлением); редактор показывает, как это будет выглядеть. Бот анонсирует игру столу с кнопками «Участвовать /
В резерв / Не смогу» (по одной в строке); ответы видны под игрой и в самом анонсе — один список на игру, в каком бы чате
игрок ни нажал. «Мест для игроков» (пусто — верхнее число из «Количества участников»: «4–5» — это 5) ограничивает участников: когда места заняты, первая кнопка становится «Мест нет», а
нажатие объясняет, что можно записаться в резерв; когда участник отказывается, бот пишет всем из резерва (тех, кто
ни разу не писал боту, упоминает под анонсом). Бот отвечает, пока открыто приложение: нажатия, пока оно закрыто,
обработаются при запуске (Telegram хранит их сутки). Поменяли игру после анонса? У игры появится
«Анонс устарел: Адрес…» — «Обновить анонс» правит отправленное сообщение, «Обновить и сообщить игрокам» ещё и отвечает
на него, что изменилось. Сдвинутое время уносит ответы с собой. Он
напоминает столу за день и за два часа (пока приложение открыто — напоминание, чьё время пришло, пока оно было закрыто,
уйдёт при открытии). «Начать игру» переключает приключение и стол, закрепляет план и открывает сцены. Расписание общее для всех хранилищ (`<данные приложения>/schedule.json`).

Таймер («Инструменты» → «Таймер»): песочные часы или цифры на экране игроков — справа вверху, справа внизу или крупно
по центру, с подписью («Пока горит факел»). Заготовки от 30 секунд до 30 минут или своё время. Когда время выходит,
часы вспыхивают «Время вышло!», а у мастера звучит сигнал (через устройство вывода музыки). Пауза, ±1 минута,
«спрятать от игроков» и «убрать» — там же и в правой панели.

Покупка характеристик («Инструменты» → «Покупка характеристик»): 27 очков, от 8 до 15 до бонусов (бюджет и пределы
можно поменять под домашние правила), цена, итог и модификатор каждой характеристики, стандартный набор одной
кнопкой. Бонусы — от предыстории (2024: +2/+1 или +1/+1/+1), от расы (2014: раса → подраса, например «Полурослик →
Легконогий»; встроены расы SRD) или свои. «Свои расы и подрасы»: новая раса или подраса к любой, в том числе
встроенной («Эльф → Лесной»), с бонусами и «+1 на выбор»; хранятся в библиотеке — общие для всех кампаний. «Проверить персонажа» берёт итоговые значения из листа
игрока, сам подбирает бонусы и говорит, законно ли распределение и сколько очков потрачено, или что нарушено;
увеличения с уровнями и черты вписываются в «Прочее».

Переделка статблока («Инструменты» → «Переделка статблока», «Переделать…» у любой карточки D&D или «+» →
«По образцу статблока…» в «Карточках»): статблок существа
за основу — старосту из обывателя, дварфа из стражника. Шаблоны: возраст (ребёнок, старик), сложение (хилый или
здоровяк), роль (главарь, бывалый боец, ловкач, целитель, мудрец), народ (человек, дварф, эльф, полурослик, гном, орк, тифлинг, драконорождённый; возраст — только для гуманоидов, народ — только для тех, у кого нет своего: гоблин или кобольд остаётся собой) — характеристики, размер,
скорость, тёмное зрение, сопротивления, особенности и язык; поверх них характеристики меняются вручную; атаку можно
заменить оружием SRD, переименовать с теми же числами (сковородка со статами дубинки) или убрать («Без оружия»),
добавить ещё оружие (атакой или только в снаряжение) и вписать в снаряжение прочие вещи; своё оружие («Своё оружие…»:
кубы, любой тип урона SRD, рукопашное или дальнобойное, фехтовальное, досягаемость, метательное с дистанцией, двумя
руками, магия +1…+3 и урон другого типа сверху — 2d6 огнём у пылающего клинка) хранится в библиотеке для всех кампаний
и выбирается, как оружие SRD; (новая атака пишется на языке и в редакции карточки, её название меняется и в мультиатаке, и в
снаряжении); «Сила» делает существо сильнее или слабее — другой ПО: бонус мастерства по правилам, а КД, хиты,
атаки, урон и СЛ сдвигаются настолько, насколько они у типичного существа этого ПО (своя таблица: медианы существ SRD,
сглаженные). Числа, которые зависят от характеристик, пересчитываются: спасброски, навыки, пассивная Внимательность,
инициатива, хиты (кость хитов — по размеру), КД по надетому доспеху, броски атаки, урон и СЛ спасбросков в текстах
блоков. Справа — получившийся статблок и список изменений; «Создать карточку» открывает его в редакторе («На основе: …»
— в заметках). Под портретом без карточки в «Персонажах» «Создать карточку» → «По образцу статблока…» открывает
инструмент для этого портрета («С нуля» — как раньше): карточка ляжет рядом с ним, с его именем и картинкой. Тексты особенностей и действий не переписываются.
«Свои» — шаблоны мастера («Культист Морского бога»: сопротивление холоду, плавание, особенность, Акван):
характеристики, размер, скорости, тёмное зрение, сопротивления и иммунитеты, владение спасбросками и навыками,
особенности, действия и реакции, язык и подвид. «Это народ» ставит шаблон к народам (табакси): по одному, гуманоиду без своего народа, а карточку этого народа
можно сделать другим и обратно. Остальные сочетаются с любыми шаблонами и подходят любому существу; хранятся в
библиотеке (`reshape-templates.json`) — общие для всех кампаний.

Вкладка «Карточки» (бестиарий): монстры и NPC со статблоком, персонажи партии с листом. Встроены все монстры из SRD 5.1 (редакция 2014) и SRD 5.2.1
(редакция 2024) на английском и русском. Поиск находит монстра на любом языке («goblin» найдёт и «Гоблина»),
фильтры — по редакции, языку и месту хранения. Монстра можно добавить в инициативу сразу пачкой: хиты, КД
и бонус инициативы подставятся сами, хиты можно бросить по формуле; из трекера статблок открывается одной кнопкой.
Если у карточки несколько картинок, они раздаются по очереди: четыре разбойника и четыре портрета — у каждого свой.
Картинку участника можно сменить в трекере: нажмите на его портрет и выберите другую из картинок карточки.

NPC — та же карточка, но лежит в папке characters рядом со своим портретом. Во вкладке «Персонажи» под портретом
с карточкой — её статблок и кнопка «в инициативу», под портретом без карточки — «Создать карточку». В карточке
хранится сторона в бою (NPC по умолчанию союзники, монстры — противники); при добавлении и прямо в трекере
сторону можно поменять.

Портреты добавляются прямо на странице карточки («+» рядом с портретом): из хранилища, из буфера обмена
или с диска. Так можно
дать портрет и встроенному монстру — он хранится в библиотеке и общий для всех языков карточки.

Персонажи игроков — карточки с листом персонажа D&D (характеристики, навыки, атаки, заклинания, умения,
снаряжение, личность) в папке party приключения; в бою — сторона «партия». Лист — справка для мастера, игрокам
не показывается. Персонажа можно импортировать из Long Story Short: экспорт листа в JSON, затем «Импорт персонажа…» во вкладке
«Персонажи» (ляжет в папку party текущего приключения) или «Импорт из файла…» в меню «+» вкладки «Карточки»:
аватар станет портретом.

Игрок переделал персонажа (например, по замечаниям мастера)? У карточки — «Обновить из LSS…»: выберите новый
экспорт, и приложение покажет, что изменилось — уровень, характеристики, хиты, КД, навыки, атаки, заклинания,
строки снаряжения и умений (+ добавилось, − пропало). Как при слиянии в git, у каждого изменения и каждой строки —
галочка «взять новое»: снятая оставляет в карточке прежнее (например, новое оружие взять, а убранную верёвку
оставить). «Обновить карточку» применяет выбранное; портреты, заметки, теги и сторона остаются, а прежняя версия
уходит в корзину приложения. Повторный импорт того же персонажа (по аватарке LSS или по имени в той же папке) тоже не создаёт копию, а показывает изменения и
спрашивает: обновить карточку, создать новую или пропустить. Лист можно завести и вести прямо в приложении: в редакторе
карточки выберите вид «Персонаж игрока».

**Заклинания-карточки LSS.** Если книга заклинаний в LSS ведётся карточками, в экспорте персонажа только номера
заклинаний, без названий. Названия приложение берёт из таблицы «Заклинания Long Story Short» (настройки «Карточки»),
её достаточно один раз загрузить:

1. Войдите в LSS в браузере и откройте «Гримуар» (longstoryshort.app/spells/).
2. Откройте инструменты разработчика (⌥⌘I / F12) → вкладка Network и обновите страницу.
3. Найдите запрос к api.longstoryshort.app со списком заклинаний (большой ответ — массив по кругам, сразу все
   заклинания редакции) и сохраните ответ в файл .json (Response → правой кнопкой → Save / «Сохранить как»).
   Переключите редакцию в «Гримуаре» (2014 / 2024) и сохраните ответ ещё раз.
4. В приложении: настройки «Карточки» → «Заклинания Long Story Short» → «Загрузить файлы…» и выберите сохранённые
   файлы. Заклинания найдутся в них сами, загрузку можно повторять — новые добавятся к прежним.

Свои заклинания игрока (созданные им в LSS) в общей базе не видны: попросите игрока так же сохранить ответ с ними
или загрузите ответ, сохранённый на открытом листе его персонажа. Чего в таблице нет, приложение перечислит в
предупреждении при импорте («не нашлось 3 из 8»); можно и переключить книгу в LSS на текст. Таблица хранится в
библиотеке (`lss-spells.json`) и попадает в резервные копии.

Статблок или лист открывается в выдвижной панели справа — из «Персонажей», «Файлов» и трекера инициативы,
не уводя с текущей вкладки (Esc или повторное нажатие — закрыть, «Во вкладке» — открыть во вкладке «Карточки»).

Броски — прямо из статблока и листа: кнопка «Атака» под действием бросает к20 и сразу урон (на натуральной 20 кубы
урона удваиваются), кнопки урона — только урон. Нажимаются и числа: модификаторы, спасброски, навыки, инициатива,
атаки в листе персонажа. Shift — с преимуществом, ⌥ — с помехой. Результаты — в журнале «Броски» в окне мастера,
игроки их не видят.

**Карты.** Картинки из папок карт (или любая картинка через «Показать как карту»). Панель карты — в две строки:
верхняя выбирает раздел — «Туман», «Обзор игроков», «Сетка», «Жетоны», «Метки», — нижняя показывает его инструменты
и настройки (рука, которая двигает карту, есть в каждом разделе; ещё — пробел или средняя кнопка мыши).

- **Туман** — открыть и скрыть кистью или прямоугольником, размер кисти, ⌘Z — отменить, «Открыть всё» / «Скрыть всё».
- **Обзор игроков** — какую часть карты видят игроки: «Вся карта», рамка (тащите — сдвигается, края и углы — меняют
  размер в пропорциях экрана игроков) или «Как у меня».
  «Как у меня» остаётся нажатой: пока она нажата, игроки следуют за каждым движением и масштабом вашей карты — удобно
  выставить картинку на экране игроков перед игрой. Нажмите ещё раз, чтобы отпустить.
- **Сетка** — значками: без сетки, квадраты или гексы (вершиной или гранью вверх); клеток по ширине, толщина,
  непрозрачность и цвет линий и инструмент сдвига: число клеток и сдвиг подгоняют сетку к нарисованной на карте.
- **Жетоны** — «Из боя» (участники текущего боя), «Партия» (герои приключения), «Размер» всех жетонов карты, «Список» —
  жетоны карты и поиск по карточкам. С сеткой жетон встаёт в клетку (на гексах — в центр гекса); под туманом игроки
  жетонов не видят.
- **Метки** — щелчок ставит метку (название, цвет, значок, заметка для себя, карточки); «Список» — все метки карты,
  кнопка рядом — видят ли игроки новые метки сразу.

У игроков туман непрозрачный, с мягким краем, обзор меняется плавно. Туман и обзор хранятся у каждой карты: её можно
подготовить заранее.

Плитки во вкладках «Персонажи» (портреты и монстры), «Фоны» и «Раздатка», а также картинки и карточки в «Файлах»
можно перетаскивать внутри своей группы (папки) — например, сложить рядом всё, что нужно для одной сцены. Порядок общий:
переставленное в «Файлах» так же стоит и во вкладках. Он запоминается в хранилище, новые картинки встают в конец,
файлы на диске не трогаются. Во время поиска перетаскивание выключено.

Блоки правой панели «Экран игроков» сворачиваются нажатием на заголовок. Пустые блоки (ничего не показано и
подборка пуста) свёрнуты в одну строку: «Карты · нет», «Музыка · тишина». Свёрнутый блок, в котором что-то есть,
отмечен точкой.

Подборка: в блоках «Фоны», «Раздатка», «Персонажи», «Карты», «Музыка» и «Инициатива» лежит то, что нужно под рукой. Щелчок по плитке выводит её на
экран игроков, ещё щелчок — убирает; то, что на экране, — в рамке со значком глаза (портретов на экране может быть
несколько, фон, карта и раздатка — по одной). Пополнить подборку можно тремя способами: всё, что выводится на экран
(из любой вкладки), попадает в неё само; плитку можно перетащить из вкладки (или карту из списка карт) на блок; кнопка
«+» открывает выбор файлов, можно отметить несколько. Крестик на плитке убирает её из подборки, но не с экрана. В плитках — только подборка; то, что на экране, но не в ней (например,
осталось от прошлой сцены), — отдельной строкой «На экране: …» с кнопками «в подборку» и «убрать с экрана». У
каждой сцены своя подборка (новая сцена начинает её со своего содержимого): можно заранее накидать в сцену всё нужное
и на игре выводить по мере надобности, не переходя по вкладкам. Пока сцена не включена, подборка — общая у
приключения; она переносится вместе с приключением (одним файлом, корзина). «Сохранить текущее» (+ в блоке «Сцены»)
берёт в новую сцену и то, что на экране, и всю подборку: можно накидать всё в панель и сохранить сценой. Сначала
спросит название (Enter — сохранить, Esc — отмена); переименовать сцену — двойной щелчок по ней. Плитки и строки
подборки переставляются перетаскиванием. Крестик у
включённой сцены — выйти из неё: на экране ничего не меняется, в панели снова подборка приключения (например, чтобы
собрать следующую сцену).

Музыка в подборке — плейлисты (папки) и отдельные треки: щелчок включает (трек — по кругу), по играющему — пауза.
Например: в башне — тема башни, на втором этаже — «Бой». Звёздочка у строки (когда сцена включена) — основная
музыка сцены: она включается вместе со сценой; ещё щелчок по звёздочке — сцена музыку не меняет. Атмосфера в подборке (в блоке «Музыка») —
зацикленные звуки поверх музыки (дождь, таверна): щелчок включает и выключает. Звуки — отдельный блок: разовые
эффекты по кнопке (дёрнули рычаг — гром), щелчок играет звук один раз поверх музыки, на то же устройство вывода; там
же громкость звуков и «остановить все». Сыграть звуком можно и любой аудиофайл в «Файлах».
В приложение встроены базовые звуки — в окне «+» они первыми, в группе «Встроенные»: 38 эффектов (гром, рычаг,
двери, замок, монеты, меч, заклинание, стекло, камни, рык чудовища, призрак, великан, вой оборотня, колокол и набат,
боевой рог, взрыв, цепи, стрелы, кнут, удар, падение тела, вой призрака, стон нежити, конь и галоп, вороны, сова,
сердцебиение, безумный смех, скрип половиц, лай собак…) и 23 петли атмосферы (лес днём и ночью, жуткий лес, костёр,
факел, подземная река, море, болото, дождь, гроза, зимний и пустынный ветер, таверна, рынок, пещера, дом с
привидениями, склеп, кузница, ночь в поле, камин, храм, пастбище, ветер в трубе). Источники и лицензии — `resources/sounds/README.md`. Бои в подборке — заготовки боёв: щелчок начинает этот бой
вместо идущего (герои, добавленные вручную, остаются) и открывает «Инициативу» (бросить инициативу), идущий бой
подсвечен, повторный щелчок выключает его вместе со всеми участниками. Так у сцены «Башня» могут быть наготове и
«Крысы», и «Гоблины» — запускается тот, что нужен. Записки в подборке — маленькими листами, записи справочника с
картинкой — картинкой.

Когда вкладки не помещаются, они сжимаются (название текущей видно всегда), а дальше полоса вкладок
прокручивается колёсиком. Вкладку можно закрыть средней кнопкой мыши.

Во вкладке «Персонажи» ниже портретов — монстры текущего приключения (карточки из его папок monsters и общие):
отсюда их удобно добавлять в бой с нужным количеством, открывать статблок и показывать портрет игрокам.

Свои карточки создаются в визуальном редакторе (кнопка «+» во вкладке «Карточки») — с живым предпросмотром статблока,
несколькими портретами и заметками мастера. Встроенную карточку можно править прямо на месте: правка сохраняется
в библиотеку и заменяет встроенную везде — в списке, боях, на картах, в поиске (в списке у неё пометка «изм.»);
«Вернуть как в SRD» убирает правку (файл — в корзину). Отдельная карточка на основе встроенной — «Сделать копию…».
Колдовство — свой раздел редактора: заклинательная характеристика, СЛ и бонус атаки (пусто — посчитаются от
характеристики и бонуса мастерства) и группы заклинаний: заговоры, «по желанию», «N раз в день», уровни с ячейками.
Названия подсказываются из справочника, в статблоке они — ссылки на записи, рядом — кнопка броска атаки заклинанием.
Колдовство, уже записанное текстом особенности (как в SRD), переносится в этот раздел кнопкой «Перенести из …».
Свои карточки — обычные JSON-файлы в папках бестиария приключений (monsters / монстры / …)
или в общей библиотеке для всех кампаний — в папке данных приложения (её можно сменить в настройках, например
положить в облако). Где хранить новую карточку или копию, приложение спрашивает; «Перенести…» перекладывает
карточку между приключениями и библиотекой без копии. В этих папках приложение само создаёт и сохраняет файлы
карточек, а картинки с диска копирует рядом с карточкой. Карточки версии 0.9 из скрытой папки
`.scrying-glass/cards` переносятся в папку `monsters` в корне хранилища при первом открытии. Формат карточки
не привязан к D&D: в нём указаны система и язык, другие ролевые системы можно будет добавить.
Файлы карточек можно править и в другой программе (или синхронизировать через облако): приложение перечитывает их
сразу. Если файл изменили, пока карточка открыта в редакторе, редактор предложит загрузить новую версию или
оставить свои правки.
У карточки может быть несколько языков: «+ язык» на странице карточки открывает перевод в редакторе.
Портреты карточек показываются игрокам кликом, в том числе из библиотеки.

Карточками можно делиться: экспорт (кнопка на странице карточки — со всеми языками, или меню «+» — вся кампания
или библиотека) сохраняет один JSON-файл вместе с портретами. Импорт из меню «+» добавляет карточки как новые
в кампанию или в библиотеку.

Музыка: любая папка с аудиофайлами (mp3, ogg, m4a, wav, flac) — плейлист. Треки сменяются с плавным переходом,
есть перемешивание и повтор. Поверх музыки можно включить атмосферу: зацикленные звуки (дождь, таверна, бой)
со своей громкостью. Звук идёт с компьютера мастера и продолжает играть, даже если экран игроков закрыт.
После запуска приложения ничего не играет само. Устройство вывода (например, колонки вместо наушников) выбирается
в настройках «Музыка» и запоминается на этом компьютере.
Горячие клавиши (⌘ на macOS, Ctrl на Windows и Linux): ⌘P — пауза, ⌘→ / ⌘← — следующий / предыдущий трек,
⌘↑ / ⌘↓ — громкость, ⌘⇧A — атмосфера, ⌘B — погасить экран игроков, ⌘1…⌘9 — сцены, ⌘K — общий поиск. Все сочетания
приложения — в ⌘, → «Горячие клавиши» (с поиском); общие — настройки, поиск, затемнение, музыка — там же можно поменять:
щёлкнуть по клавишам и нажать новое сочетание. Нужна ⌘/Ctrl или Alt (F1–F12 можно и одни); системные (копировать,
вставить, отменить, выйти…) и занятые не принимаются. Сцены переезжают рядом: нажмите, например, ⌥1 — и они станут
⌥1…⌥9. Подсказки у кнопок показывают текущие клавиши: «Поиск · ⌘K».

Резервные копии (настройки → «Резервные копии»): приложение само делает снимки всего, что создано в нём, — сцены,
туман, метки и жетоны карт, заготовки боёв, записки, карточки, библиотека (без картинок) и настройки.
Снимок — при открытии хранилища, раз в полчаса работы (если что-то изменилось) и при выходе; хранятся последние 20
и по одному на день за месяц, сделанные вручную — всегда. Папку снимков можно выбрать (например, в облаке) —
уже сделанные снимки переезжают туда, полная копия по умолчанию тоже предлагается туда. «Восстановить…» возвращает данные хранилища и/или
библиотеку; перед этим сохраняется снимок нынешнего состояния. Снимки лежат в папке данных приложения (`backups`).
Картинки и музыку снимки не копируют — это ваши файлы, их берегите Time Machine или облаком.
«Полная копия в файл» там же: один файл `.sgbackup` — настройки, вся библиотека и данные хранилища (по галочке —
вместе с картинками и музыкой). «Восстановить из файла…» — в это хранилище или в другую папку (например, на новом
компьютере): файлы копии заменяют такие же, остальные остаются, структура папок (и пустые папки) возвращается.

Приключение одним файлом (меню переключателя приключений над боковой панелью): «Экспорт «…»…» сохраняет файл
`.sgpack` — папку приключения со всеми картинками, записками и карточками (музыку — по желанию), его
сцены, карты с туманом, метками и жетонами, заготовки боёв, порядок плиток и общие карточки, на которые ссылаются
заготовки и метки. «Импорт приключения…» добавляет его в открытое хранилище: если такое название уже есть,
приложение спросит другое; пути пересчитываются сами; общие карточки попадают в библиотеку (свои не
перезаписываются). Перед импортом делается снимок. `.sgpack` — обычный ZIP.
**Репозиторий приключений** («Найти приключения…» и «Опубликовать «…» в репозитории…» в меню приключения или
«Настройки» → «Сообщество» → «Обзор»): своими приключениями можно поделиться с другими мастерами, а их —
скачать. Каталог показывает все включённые источники: репозиторий приложения и любые другие, добавленные по адресу
(например, вашей компании игроков или клуба). Публикуется `.sgpack` (музыка и
PDF — по вашему выбору; картинки уходят легче: PNG без прозрачности — как JPEG, стороны до 4096 точек, ваши
файлы не меняются) с названием, описанием, языком и обложкой; новая версия заменяет прежнюю, снять
приключение можно в любой момент. Что-то не так с чужим приключением — «Пожаловаться…»: жалобу получит
администратор репозитория (он видит жалобы в каталоге, введя токен администратора в «Настройки» → «Сообщество»). Скачанным приключениям предлагаются новые версии (старая копия уходит в корзину).
Ваши приключения привязаны к ключу автора, который создаётся при первой публикации. В «Настройки» → «Сообщество»
можно посмотреть его 24 **слова восстановления** — запишите их на бумаге, и «Восстановить по словам…» вернёт тот же
ключ на другом компьютере или после переустановки (ещё ключ можно сохранить в файл и загрузить). Пока копии нет,
после публикации об этом напоминает плашка («Показать слова восстановления…», «Сохранить ключ в файл…», «Уже
сохранён», «Позже» — на три дня). Сервис репозитория — в `server/`
(с Helm-чартом).
Там же — **система** приключения (D&D 5e 2024 или 2014, Fate Core, Mausritter, Forged in the Dark; для «Всего хранилища» — система по
умолчанию). Карточки, подсказки боя, поиск ⌘K и справочник показывают то, что подходит этой системе (обе редакции
D&D — вместе), встроенный SRD и инструменты D&D (сложность боя, покупка характеристик) — только в приключениях D&D.
Запись справочника привязывается к системе полем `system:` в шапке (`fate-core`, `dnd5e` …); без него заклинания,
предметы, черты и состояния считаются записями D&D, а правила и заметки подходят любой системе.
Ненужные системы отключаются в настройках (раздел «Ролевые системы»): их контента больше не видно
нигде — ни карточек, ни записей SRD, ни приключений с такой системой (вместе со сценами и заготовками боёв). Файлы
остаются на месте: включите систему — всё вернётся. Приключения, созданные до выбора систем, считаются D&D 5e (2024).

**Fate Core** — пакет системы: установите его в «Сообщество» → «Системы» («Настройки» → «Ролевые системы» → «Найти
системы»), его можно удалить и поставить снова. Карточка (одна для персонажей игроков и NPC): важность NPC, концепция,
проблема и другие аспекты, восемнадцать навыков (видны только выше нуля; щелчок — 4dF + навык в журнал, итог назван по
лестнице: «Хорошо»), трюки, восстановление, физический и ментальный стресс (клетки по Телосложению и Воле), лёгкое,
среднее и тяжёлое последствия. Трекер в Fate-приключении: очерёдность по Внимательности без броска, обе дорожки
стресса щелчком, последствия текстом, «вывести из боя», аспекты на участниках вместо состояний; портрет у игроков краснеет по отмеченному стрессу и последствиям.
Блок «Аспекты и жетоны» в правой панели (только в Fate): аспекты сцены с бесплатными призывами (скрытые игроки не
видят, пока их не откроют) и жетоны судьбы — у персонажей партии (кнопка «Партия», восстановление из карточки;
«Новая сессия» — до восстановления) и у мастера («новая сцена» — по жетону на персонажа). Игроки видят аспекты
и жетоны (у портретов) в выбранных углах экрана — по умолчанию слева и справа внизу; угол выбирается схемой у
заголовка, рядом — глаз: показывать ли.

Персонажа игрока D&D можно отправить в Telegram картинкой бумажного листа персонажа (кнопка с самолётиком на карточке): характеристики, спасброски и навыки, КД, хиты, атаки, заклинания, умения и снаряжение — с подписями на языке карточки.

**Mausritter** — тоже пакет системы («Сообщество» → «Системы»). Одна карточка для существ и мышей: защита (Hit
Protection), СИЛ, ЛОВ, ВОЛ, броня, атаки (щелчок по строке — бросок её куба урона), критический урон, особенности,
желания, масштаб отряда. У мыши есть и лист: уровень, опыт, пипсы, прошлое, знак рождения, шёрстка, примета,
стойкость и десять клеток инвентаря (две лапы, два тела, шесть в рюкзаке) с отметками износа; состояние занимает
клетку. Щелчок по СИЛ, ЛОВ или ВОЛ — спасбросок: к20 не выше характеристики (Shift — с преимуществом, меньший из
2к20; ⌥ — с помехой). Трекер в приключении Mausritter: защита, СИЛ / ЛОВ / ВОЛ сейчас и максимум; урон сверх защиты
уходит в СИЛ, при СИЛ 0 участник выбывает; без броска очерёдности (мыши ходят до или после противников по спасброску
ЛОВ — порядок списка); состояния Mausritter. **«Инструменты» → «Мышь»** (только в приключениях
Mausritter) создаёт мышь по правилам SRD: характеристики (3к6, два лучших — кубы видны, две характеристики можно
поменять местами), защита и пипсы, прошлое и две его вещи (слабой мыши — вещи ещё одного прошлого), факелы, пайки,
оружие, знак рождения, шёрстка, примета и имя; «Создать карточку» открывает лист мыши с разложенным инвентарём
(оружие в лапах, броня на теле, остальное в рюкзаке), «В журнал» и «Копировать» — текстом. **«Инструменты» →
«Таблицы Mausritter»** бросают по таблицам мастера из SRD по их правилам: мышиное поселение (размер — меньший из
2к6, управление — к6 + размер, у городов и городков по две особенности или промысла, название и, начиная с хутора,
таверна), гекс (ориентир по виду гекса, подробность по к6 и к8), место приключения (тема и N комнат: вид, существо,
сокровище и что там), сокровища (ещё к20 за каждое «да»; волшебные мечи с проклятием 1 из 6, заклинания, пипсы
посчитаны), мышь мастера, наёмники (спасбросок ВОЛ или 20 п, потом сколько ищут работу; у каждого к6 защиты и 2к6 на
характеристики, карточка в один щелчок), завязка приключения, погода и событие сезона (плохая погода отмечена) и
реакция. Выпавшие кубы видны; «В журнал» и «Копировать» — Markdown. **«Инструменты» → «Фракции»** хранят фракции
приключения: ресурсы, цели с отметками продвижения (щелчок отмечает), «Между сессиями» бросает за текущую цель каждой
фракции к6 + её подходящие ресурсы − ресурсы соперника (4–5 — отметка, 6+ — две; достигнутая цель — подсказка дать
новый ресурс); десять фракций-примеров из SRD добавляются из списка. Блок **«Исследование»** в правой панели считает
ходы в месте приключения (каждый третий — бросок встречи: 1 — встреча, 2 — знак; каждый шестой — износ факелов) и
стражи пути (четыре в сутки; утренняя и вечерняя начинаются с броска встречи и её часа). Фракции и счётчик — часть
приключения: уходят в .sgpack и в корзину вместе с ним. **«Инструменты» → «Постройки»** считают нору по SRD: комнаты
(бедные, обычные, роскошные) и туннели в кубах по 6" дают цену материалов, содержание (1 % в месяц), срок работ для
стольких землекопов (трое выкапывают куб земли в день, другие материалы — вдвое дольше) и плату им; «В журнал» пишет
план таблицей.

**Forged in the Dark** (SRD Blades in the Dark; без мира Blades). Одна карточка для негодяев и NPC: роль,
происхождение, прошлое, порок; двенадцать действий с точками 0–4 под Проницательностью, Удалью и Решимостью; стресс
0–9, травмы, вред (два лёгких, два средних, один тяжёлый), броня, особые способности, снаряжение, монеты, тайник и
опыт; уровень NPC. Щелчок по действию — бросок действия на его точки (6 — полный успех, 4–5 — частичный, 1–3 —
неудача, две шестёрки — крит; без точек — 2к6, меньший), по атрибуту — бросок сопротивления (стресс = 6 − лучший куб,
крит снимает один). В трекере нет инициативы: порядок списка, дорожка стресса из девяти клеток и пять строк вреда,
свободные состояния. Часы прогресса (правая панель) — часть этой системы. **Банда** приключения — «Инструменты» →
«Банда»: название, тип, репутация, логово, охотничьи угодья, знакомый; уровень и хватка, репутация с территорией
(полная шкала укрепляет хватку или покупает следующий уровень за уровень × 8 монет), жар (на 9 — розыск, излишек
переходит) и розыск, монеты против вместимости хранилища, опыт банды, особые способности, улучшения, владения,
подручные (шайки и специалисты с качеством, достоинствами, недостатками и вредом) и фракции (уровень, хватка,
отношение −3…+3; война отмечается). «После дела» считает репутацию по уровню цели, жар — по шуму и обстоятельствам,
монеты — по добыче; «Неприятность» бросает кубы розыска в столбце жара и ведёт по ссылке в правила. Жар, розыск,
репутация, монеты и бросок неприятностей — под рукой в правой панели. Банда уходит в .sgpack и в корзину вместе с
приключением. This work is based on Blades in the Dark (found at http://www.bladesinthedark.com/), product of One Seven Design, developed and authored by John Harper, and licensed for our use under the Creative Commons Attribution 3.0 Unported license (http://creativecommons.org/licenses/by/3.0/).
«Удалить «…»…» там же: папка приключения уходит в корзину, из приложения убираются его сцены, заготовки боёв
и разметка карт; из корзины приключение возвращается вместе с ними. Перед удалением делается снимок.
Там же — «Экспорт партии…» (листы персонажей игроков приключения с портретами — одним файлом карточек) и «Импорт
персонажей…» (такой файл или выгрузка Long Story Short — сразу в папку партии текущего приключения).

**Системы, описанные файлом** (пакеты систем, первая версия): система может быть не кодом, а JSON-файлом — разделы и
поля карточки (числа, тексты, выбор, точки, дорожки клеток, метки, списки, формулы), броски у полей (к20 + бонус, к100
под значение с трудным и экстремальным успехом, 2к6 с полосами исходов, пул кубов с успехами или лучшим кубом и
перебросом, 4dF, сумма, взрывающиеся кубы) и что показывает трекер инициативы. По нему приложение рисует карточку,
редактор, броски и трекер. Пробные пакеты — в Сообществе («Найти приключения» → «Системы» или «Настройки» → «Ролевые
системы» → «Найти системы»): **«Пул шестёрок»** (по мотивам Year Zero: атрибуты и навыки бросают пул к6, считаются
шестёрки, бросок можно перебросить) и **«Ужасы на к100»** (к100 под характеристики и навыки); их файлы — в
`samples/systems/`. При самом первом запуске включены только две редакции D&D; Fate Core, Mausritter и Forged in the
Dark включаются в «Настройки» → «Ролевые системы», там же пакетные системы можно удалить. Свои системы собираются в **«Инструменты» → «Конструктор систем»** (он же — из
«Настройки» → «Ролевые системы»): разделы и поля, бросок у каждого поля, трекер, с живым предпросмотром карточки, где
можно попробовать броски; встроенную систему можно скопировать и переделать. Они сохраняются в папку `systems/`
библиотеки (видны во всех хранилищах), их можно выгрузить в файл и загрузить. У системы может быть свой **справочник**
(правила, состояния, снаряжение — записи Markdown, в её приключениях они как встроенные; состояние в трекере открывает
свою запись), а сама система **публикуется в Сообществе** («Опубликовать…» в конструкторе): «Найти приключения» →
«Системы», «Установить систему» кладёт её в библиотеку, о новых версиях приложение сообщает при запуске. Приключение
на системе, которой у вас нет, скажет об этом и предложит её установить.

**Бестиарии в Сообществе**: своими карточками (монстры, NPC, с картинками) можно поделиться бестиарием — «Карточки» →
«+» → «Опубликовать бестиарий…» (или «Сообщество» → «Бестиарии»): отметьте карточки, дайте название, описание и
обложку. «Добавить в библиотеку» кладёт чужой бестиарий в вашу библиотеку («Карточки», все кампании); новая версия
заменяет его карточки, «Убрать из библиотеки» отправляет их в корзину библиотеки.

Картинки, карты и треки можно удалить из приложения («⋯» или правый щелчок → «Переместить в корзину»).

**Корзина** — своя, как в Obsidian: удалённые файлы, карточки, записи справочника и приключения
переезжают в скрытую папку `.trash` хранилища (или библиотеки — для общих), а не в системную корзину, которую
могут очищать сами. «Файлы» → «Корзина» внизу дерева: что, откуда и когда удалено, «Вернуть» на прежнее место
(папки, которых уже нет, создаются; занятое имя — «x (2)»), «Удалить навсегда» и «Очистить корзину».
В настройках («Файлы» → «Корзина») можно включить автоочистку — через неделю, 30 или 90 дней, через год — или
удалять сразу, без корзины.

 В папках карточек (monsters, characters, party) «Файлы» показывают и сами
карточки: их можно открыть, перенести и удалить (вместе с картинками — по выбору), а кнопки «Новая карточка»
и «Импорт карточек…» создают и импортируют карточки прямо в открытую папку. Картинку из буфера обмена (скриншот, «Копировать изображение» в браузере,
файл, скопированный в Finder) можно вставить в открытую папку во «Файлах» кнопкой «Вставить» или ⌘V. Во вкладках «Персонажи», «Фоны», «Раздатка», «Карты» и
«Музыка» есть такая же кнопка и ⌘V: файлы, скопированные в Finder или Проводнике (все сразу; в «Музыке» — музыка), или
картинка попадают в папку этой вкладки в текущем приключении (без приключения — в корне хранилища). Разбираться в
папках не обязательно: перетащите файлы из Finder или Проводника на одну из этих вкладок или на её значок в полосе
слева — они скопируются в нужную папку (куда — видно во время перетаскивания; файлы не того вида пропускаются, с
пояснением). Приложение следит за папкой: новые и удалённые файлы видны сразу. Файлы пользователя не меняются,
свои данные (подписи, что на экране) приложение хранит в `.scrying-glass/state.json` внутри хранилища.
Пути там относительные, так что хранилище можно синхронизировать между компьютерами.

Данные версии 0.3 (подключённые папки и картинки, добавленные вручную) приложение предложит перенести
при первом открытии хранилища.

## Структура проекта
TypeScript + Svelte 5 + Electron, сборка через electron-vite. Интерфейс в духе Obsidian:
полоса модулей слева, боковая панель, вкладки, справа превью экрана игроков. Настройки: ⌘, (Ctrl+,).

- src/main/: ядро (состояние, хранилище, сохранение, окна, перенос данных старых версий)
- src/preload/: мост между окнами и ядром (window.api)
- src/shared/: общие типы; состояние и действия выводятся из списка модулей; vault.ts — дерево хранилища
- src/renderer/control/: окно управления (оболочка, вкладки, настройки, панель экрана игроков)
- src/renderer/display/: окно экрана игроков
- src/renderer/lib/: общее для окон: состояние, тема, сцена экрана игроков (Stage.svelte)
- src/modules/<имя>/: функции приложения
  - main.ts: состояние и действия ядра (defineModule)
  - control.ts: что модуль добавляет в окно управления (defineControl): иконку, вкладку,
    боковую панель, блок на панели экрана игроков, раздел настроек, действия с картинками и треками,
    невидимый фоновый компонент (так устроен проигрыватель музыки)
  - display.ts: слой на экране игроков (defineDisplay)
  - ui/: Svelte-компоненты модуля
- src/systems/<система>/: ролевые системы для карточек: характеристики, статблок, редактор, трекер (D&D 5e, Fate Core, Mausritter, Forged in the Dark)
- resources/srd/: встроенный бестиарий, собирается скриптом scripts/import-srd.ts
- src/modules/index.ts: список модулей ядра, новый модуль вписывается сюда;
  control.ts и display.ts окна подхватывают сами

Для тестов можно запустить приложение с отдельной папкой данных: `SG_USER_DATA=/путь npm run dev`.
