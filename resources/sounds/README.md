# Встроенные звуки

Звуки и атмосфера, которые есть в приложении сразу (блок «Звуки» и атмосфера в «Музыке», кнопка «+» подборки).
Файлы только читаются; в состоянии их пути — `sound:sfx/…` и `sound:ambience/…`. Названия файлов — подписи в
приложении. Форматы: .ogg — как в источнике, .m4a — перекодировано (AAC; эффекты из WAV — 128 кбит/с, атмосфера из
MP3 320 кбит/с — 112 кбит/с), без других изменений.
