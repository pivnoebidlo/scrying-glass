# Mausritter — package

The system pack (`system/mausritter.json`), the creatures (`bestiary/`) and the compendium, built by
`scripts/build-mausritter.ts` (`npm run build-mausritter`). Do not edit the built files by hand.
`npm run build-content` packs it; the official author publishes it. Raise `release` in `content.json` when the files
change.

The files are built from the Mausritter SRD 2.3.1 (`scripts/mausritter-srd.en.md`, https://mausritter.com/srd) and its
Russian translation made for Scrying Glass (`scripts/mausritter-srd.ru.md`; the SRD licence allows translation). /
Русский перевод Mausritter SRD сделан для Scrying Glass. The text is split into entries and cards; headings and links
