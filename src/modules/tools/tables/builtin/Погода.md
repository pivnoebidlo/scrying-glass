# Погода

1-3: Ясно, лёгкий ветер.
4-5: Облачно, прохладно.
6-7: Туман до полудня.
8-9: Моросящий дождь весь день.
10: Ливень с грозой: путь займёт вдвое больше времени.
11: Сильный ветер: стрельба с помехой, костёр не развести без укрытия.
12: Необычное — {град размером с орех|кровавый закат|снег посреди лета|тишина: ни ветра, ни птиц}.
