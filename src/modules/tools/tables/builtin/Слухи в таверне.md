# Слухи в таверне

- Мельник разбавляет муку мелом — уже двое слегли.
- В старом колодце по ночам кто-то поёт.
- Сын старосты сбежал с бродячими артистами.
- На северной дороге пропал целый обоз — ни людей, ни лошадей.
- Жрец храма по ночам ходит на кладбище.
- Кто-то скупает все серебряные ложки в округе.
- В лесу видели оленя с горящими глазами.
- Стражу сменили неделю назад — новые никого не знают в лицо.
- Ведьма с болот снова берёт заказы.
- Трактирщик прячет в подвале что-то, что скребётся.
- Из шахт вернулись не все — и вернувшиеся молчат.
- Купец из столицы ищет охрану и платит вдвое.
- В реке поймали рыбу с золотым кольцом в брюхе.
- Говорят, графиня давно умерла, а правит её двойник.
- Гоблины с холмов предлагают торговать, а не грабить.
- Старый маяк зажёгся сам по себе.
- На ярмарке появился торговец, который продаёт сны.
- Кузнец выковал меч, и с тех пор не спит.
- Дети играют в новую считалку — и никто не знает, кто её придумал.
- За поимку одноглазого вора назначили сто золотых.
