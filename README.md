# Scrying Glass

Запуск:

    npm install --save-dev electron
    npm start

## Папки приключений

Кнопка «Подключить папку…» понимает такую структуру:

    Adventures/
    └── Тыквенный фестиваль/
        └── characters/
            ├── староста_гилберт.jpg
            └── char1.jpg

Можно выбрать папку одного приключения (Тыквенный фестиваль) или папку, в которой лежат
несколько приключений (Adventures): тогда подключатся все сразу.
Папка с персонажами может называться characters или персонажи.
Имя подписи берётся из имени файла (подчёркивания становятся пробелами) и редактируется в приложении.
Файлы из подключённых папок не копируются и не изменяются. Папки перечитываются при запуске
и по кнопке «Обновить».

## Структура проекта
- main.js: ядро (окна, состояние, сохранение, загрузка модулей)
- preload.js: мост между окнами и ядром
- control/ и display/: каркас окон управления и экрана игроков
- modules/<имя>/: функции приложения (main.js, control.js, display.js)
